# Release Notes – BetterKick v1.0.0

Esta es la **versión 1.0.0 de BetterKick**, el primer lanzamiento estable tras el rebranding de la antigua extensión de descarga de VODs para Kick. Aquí se resumen las características que ofrece actualmente la extensión, organizadas por tipo de usuario.

---

## 🧩 Funciones para uso general

- **Descarga de VODs completos** directamente desde la página del stream o del VOD.
- **Descarga seccionada**: elige un rango de tiempo (inicio/fin) para guardar solo la parte del VOD que necesitas.
- **Animaciones al seguir o dejar de seguir** a alguien en la web de Kick, haciendo más visibles estas acciones.
- **Amplificador de sonido integrado**, con control de ganancia de hasta **+48 dB** para mejorar el volumen de streams bajos (úsalo con moderación para evitar distorsión).

---

## 🛡️ Funciones para moderadores

- **Grabación del stream en tiempo real**: inicia una grabación mientras el directo está en curso y guarda el resultado en tu equipo.
- **Resaltado del primer mensaje de cualquier usuario en el chat**, usando una **base de datos interna** para identificar cuándo es la primera vez que escribe.
- **Resaltado de mensajes con palabras clave configurables**, ideal para detectar bots, trolls o cualquier tipo de usuario de un vistazo.
- **Biblioteca de comandos para moderación**: guarda comandos frecuentes (por ejemplo, para bots del servidor) y envíalos al chat con un solo clic.
- **Fijado temporal de mensajes**: al fijar un mensaje, puedes elegir cuánto tiempo permanecerá anclado antes de limpiarse automáticamente.

---

## 🔒 Privacidad y tratamiento de datos

- **BetterKick no recolecta datos personales ni de uso**: no se guarda tu historial de navegación, mensajes de chat, identificadores de cuenta ni métricas de telemetría.
- La configuración que uses (por ejemplo, palabras clave o comandos de la biblioteca) se almacena localmente en el navegador, únicamente para que la propia extensión funcione.

Muy importante:

- **NO RECOLECTAMOS DATOS** para vender, analizar o compartir con terceros.
- **LA DESCARGA Y LA GRABACIÓN DE LOS STREAMS SE REALIZA SIEMPRE DESDE LOS SERVIDORES DE KICK**, directamente hacia tu navegador. BetterKick no utiliza servidores intermedios propios para procesar el vídeo ni el audio.

---

## 🌍 Compatibilidad

- Diseñado para funcionar sobre **Kick.com** y los dominios asociados de la plataforma.
- Compatible con navegadores basados en Chromium y, en su caso, con Firefox según las limitaciones del motor de extensiones.

---

Si encuentras algún problema, comportamiento extraño o tienes sugerencias de nuevas funciones, considera abrir un issue en el repositorio o contactar al desarrollador antes de dejar una reseña negativa: muchas cosas se pueden solucionar rápidamente en una actualización de BetterKick.

# Release Notes – BetterKick v1.0.0 (English)

This is the **BetterKick v1.0.0** release, the first stable version after the rebranding of the former Kick VOD downloader extension. Below is a summary of the current features, organized by user type.

---

## 🧩 General Features

- **Full VOD downloads** directly from a stream or VOD page.
- **Segmented downloads**: choose a time range (start/end) to save only the part of the VOD you need.
- **Follow/Unfollow animations** on Kick, making these actions more visible on the site.
- **Built‑in audio amplifier**, with up to **+48 dB** gain to boost low‑volume streams (use with care to avoid distortion).

---

## 🛡️ Moderator Features

- **Live stream recording**: start recording while the stream is live and save the result to your computer.
- **Highlight first‑time chat messages** from any user, using an **internal database** to detect the first time they write.
- **Keyword‑based message highlighting**, ideal for spotting bots, trolls, or any user at a glance.
- **Moderation command library**: save frequent commands (e.g., for server bots) and send them to chat with one click.
- **Temporary pinning of messages**: when pinning a message, choose how long it stays before auto‑clearing.

---

## 🔒 Privacy & Data Handling

- **BetterKick does not collect personal or usage data**: no browsing history, chat messages, account identifiers, or telemetry are recorded.
- Your settings (e.g., keywords or command library) are stored locally in the browser, solely to make the extension work.

Important:

- **WE DO NOT COLLECT DATA** to sell, analyze, or share with third parties.
- **ALL DOWNLOADS AND LIVE RECORDINGS ARE FETCHED DIRECTLY FROM KICK’S SERVERS**, straight to your browser. BetterKick does not use intermediate servers to process video or audio.

---

## 🌍 Compatibility

- Designed to work on **Kick.com** and associated platform domains.
- Compatible with Chromium‑based browsers and Firefox, subject to extension engine limitations.

---

If you run into issues, odd behavior, or have feature suggestions, please open an issue in the repository or contact the developer before posting a negative review: many things can be fixed quickly in a BetterKick update.
